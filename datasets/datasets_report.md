# Datasets Referenced in the Citation Detection Paper Collection

Overview of the four standalone, reusable datasets found across the 21-paper collection, plus an assessment of how directly each one applies to the "misinterpreted but genuine citation" research topic.

---

## 1. Dataset Overview

| Name | Source | Description | Application | Link |
|---|---|---|---|---|
| **FEVER** | Thorne et al., 2018, NAACL-HLT | 185,445 claims generated by altering Wikipedia sentences, labeled SUPPORTS / REFUTES / NOT ENOUGH INFO with evidence sentences. | General-domain benchmark for the retrieval → evidence-selection → entailment pipeline used by nearly all later claim/citation verification systems. | [fever.ai/dataset/fever.html](https://fever.ai/dataset/fever.html) |
| **SciFact** | Wadden et al., 2020, EMNLP ("Fact or Fiction") | 1.4K expert-written scientific claims paired with PubMed abstracts, annotated SUPPORT / REFUTE / NOINFO with rationale sentences. | Standard benchmark for scientific claim verification; underlies most citation-content-checking pipelines (e.g., VeriSci, MultiVerS). | [huggingface.co/datasets/allenai/scifact](https://huggingface.co/datasets/allenai/scifact) |
| **SciFact-Open** | Wadden et al., 2022, Findings of EMNLP | Open-domain extension of SciFact evaluated against a 500K-abstract corpus, using pooled annotations from four state-of-the-art models. | Tests whether claim-verification models generalize beyond a small curated corpus to a realistic, large-scale literature-search setting. | [github.com/dwadden/scifact-open](https://github.com/dwadden/scifact-open) |
| **SciClaimHunt** (+ Num) | Kumar et al., 2025, arXiv / IJCNN 2025 | ~110,000 LLM-generated claim–evidence pairs derived from full research papers, including a numeric-reasoning subset. | Large-scale training/evaluation resource for scientific claim verification models, complementary to SciFact. | [huggingface.co/datasets/AnshulS/dataset_for_scicllaimhunt](https://huggingface.co/datasets/AnshulS/dataset_for_scicllaimhunt) |

## 2. Relevance to the Research Topic

*Topic: detecting citations that point to a real, existing source but misrepresent, oversimplify, or contradict what that source actually says.*

| Name | Relevant? | Why |
|---|---|---|
| **FEVER** | 🟡 Partial | General-domain fact verification (Wikipedia claims), not built from real citations to real papers. Matters only as the architectural ancestor (retrieval → evidence selection → entailment) that citation-verification pipelines borrow — not as citation data itself. |
| **SciFact** | 🟢 Yes, directly | Claims are literally rewritten from citation sentences and checked against the abstract of the actual cited paper — the closest existing dataset to "is this citation's claim genuinely supported by its source." |
| **SciFact-Open** | 🟢 Yes, directly | Same claim-vs-source verification task as SciFact, scaled to a 500K-abstract open-domain search — relevant for testing whether detection methods hold up at realistic literature scale rather than a small curated set. |
| **SciClaimHunt** | ⚪ Indirect | Claims are LLM-generated from paper text rather than derived from real citing sentences, so it's a general scientific-claim-verification resource — useful for training/evaluating underlying NLI models, but not itself a dataset of real misrepresented citations. |

---

**Summary:** SciFact and SciFact-Open match the "misinterpreted but genuine citation" framing directly. FEVER and SciClaimHunt are useful supporting infrastructure and training data but are not citation-specific.
