# Add these files to your existing GitHub repository

1. Unzip this package locally. **Do not upload the ZIP as a single file** if you want the repository to show individual source files.
2. Open the repository and your `post mid-sem` folder on GitHub while signed in with write access.
3. Use **Add file → Upload files** and drag in `README.md`, `requirements.txt`, `.gitignore`, and the `scripts/`, `config/`, `results/` folder contents. If GitHub's UI does not preserve folders, create folders using **Add file → Create new file** and a path like `scripts/run_abstention.py`, then paste/upload individual files.
4. Commit with a message such as `Add reproducible CPU abstention analysis`.
5. Keep the existing paper PDF. Do not upload the raw four JSONL input files until redistribution permissions have been checked.

This package contains no model checkpoints or original claim-text dataset. It includes small aggregate result CSVs and code.
